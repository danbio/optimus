# Claude Code / Orquestradores

As regras de instrução (System Prompting), Memória de longo termo, Roadmaps arquiteturais e Logbook de Sessões (Diário) **foram migrados** para estabelecer uma SSOT (Single Source of Truth) de contexto múltiplo-agente.

> **PARE TUDO.** NÃO CRIE LÓGICAS OU CÓDIGOS ANTES DE LER ESTAS PASTAS.

**Seu comportamento e stack dev são definidos por:**
📋 E Leia sempre: `/.agent/INSTRUCTIONS.md` (A Stack e o Que NÃO fazer)
🛣️ E Consulte: `/.agent/ROADMAP.md` (Nossos gargalos e dívidas técnicas atuais)
📓 E Mantenha atualizado: `/.agent/DIARIO.md` (As atas e o controle histórico de sessões)

## Trabalhando com VSCode / Outros LLMs

Essa estrutura unificada permite que ferramentas como GitHub Copilot, Gemini Antigravity, Cline e Claude Code compartilhem a mesma memória referenciável da base `.agent/`.

Não crie diretrizes em silos na sua própria subpasta local se puder evitar.
